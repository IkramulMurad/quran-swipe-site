# Quran Swipe — Support

Quran Swipe shows the Quran one ayah at a time: swipe up for the next ayah, with the Arabic, pronunciation and M. M. Pickthall's English translation, plus recitation, bookmarks, search and an Ayah of the Day widget.

## Get help or report a problem

[Open an issue](https://github.com/IkramulMurad/quran-swipe-site/issues/new) on this site's GitHub page (a free GitHub account is needed). Please include your iPhone or iPad model, the iOS version and, for a text problem, the ayah reference (for example 2:255).

## Common questions

**Recitation does not play.** The first time you play an ayah it is downloaded, so an internet connection is needed. After that it plays offline.

**The daily reminder does not arrive.** Check that notifications are allowed for Quran Swipe in the Settings app, and that the reminder is on in Quran Swipe → Settings → Daily ayah.

**How do I add the widget?** Touch and hold the Home Screen or Lock Screen, tap Edit or Customise, then add "Ayah of the Day" from Quran Swipe.

## Privacy

Quran Swipe collects no data. Read the [privacy policy](privacy.html).
